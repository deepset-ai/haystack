# Step Budget Reminder

`StepBudgetReminderHook` tells the model how many steps it has left before the Agent reaches `max_agent_steps`. Without a warning, the Agent can hit the limit in the middle of its research and stop without a final answer. With the reminder, it can wrap up and answer within the steps it has left.

:::warning

:::

## Overview

Before each of the Agent's last `remind_within_steps` LLM calls, `StepBudgetReminderHook` adds a reminder telling the model how many steps are left:

- With more than one step left: `You have 2 of 10 steps remaining before this run is stopped. Stop gathering information and start working toward your final answer.`
- On the last step: `This is your last step of 10. Give your final answer now: you will not see the results of any further tool calls.`

A step is one LLM call plus the tool calls it requests.

The reminder is a user message wrapped in `<system-reminder>` tags and marked with `meta={"system_reminder": True}`. [Context compaction](./compaction.mdx) uses this marker so it never mistakes a reminder for the user's task.

Reminders stay in the conversation and appear in the Agent's `messages` output. Earlier messages are left unchanged, so prompt caching keeps working.

## Usage

Register the hook under `before_llm`. With `max_agent_steps=8` and `remind_within_steps=2`, the model is reminded before its 7th and 8th LLM calls:

```python
from typing import Annotated

from haystack.components.agents import Agent
from haystack.components.generators.chat import OpenAIResponsesChatGenerator
from haystack.dataclasses import ChatMessage
from haystack.hooks.budget import StepBudgetReminderHook
from haystack.tools import tool


@tool
def search(query: Annotated[str, "The search query"]) -> str:
    """Search the web."""
    # Placeholder: would call a real search API
    return f"Some facts about {query}."


agent = Agent(
    chat_generator=OpenAIResponsesChatGenerator(model="gpt-5.4-nano"),
    tools=[search],
    system_prompt="You are a research assistant. Search each aspect separately before answering.",
    max_agent_steps=8,
    hooks={"before_llm": [StepBudgetReminderHook(remind_within_steps=2)]},
)

result = agent.run(
    messages=[
        ChatMessage.from_user(
            "Research capybaras: size, diet, social life, swimming, predators, lifespan and temperament."
        )
    ]
)

print(result["exit_reason"])
# >> text
```

This example requires the `OPENAI_API_KEY` environment variable.

### Handling runs that still hit the step limit

The model can ignore the reminder and keep calling tools. If the last step calls tools, they still run, but the Agent stops with `exit_reason` set to `"max_agent_steps"` before the model sees their results. To make sure the run always ends with an answer, combine the reminder with an `after_run` hook that handles that exit reason:

```python
from haystack.components.agents.state import State
from haystack.hooks import hook


@hook
def explain_stop(state: State) -> None:
    if state.get("exit_reason") == "max_agent_steps":
        state.set(
            "messages",
            [ChatMessage.from_assistant("I ran out of steps before finishing.")],
        )


agent = Agent(
    chat_generator=OpenAIResponsesChatGenerator(model="gpt-5.4-nano"),
    tools=[search],
    max_agent_steps=8,
    hooks={
        "before_llm": [StepBudgetReminderHook(remind_within_steps=2)],
        "after_run": [explain_stop],
    },
)
```

## Writing your own reminder

Any `before_llm` hook can add a system reminder. Mark the message with `meta={"system_reminder": True}` so context compaction doesn't treat it as the user's task. For example, this hook repeats a fixed instruction every three steps:

```python
@hook
def cite_sources(state: State) -> None:
    step_count = state.get("step_count")
    if step_count and step_count % 3 == 0:
        state.set(
            "messages",
            [
                ChatMessage.from_user(
                    "<system-reminder>\nCite a source URL for every claim.\n</system-reminder>",
                    meta={"system_reminder": True},
                )
            ],
        )


agent = Agent(
    chat_generator=OpenAIResponsesChatGenerator(model="gpt-5.4-nano"),
    tools=[search],
    hooks={"before_llm": [cite_sources]},
)
```
