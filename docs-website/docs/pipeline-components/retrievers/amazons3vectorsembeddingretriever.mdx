# AmazonS3VectorsEmbeddingRetriever

<div className="key-value-table">

|  |  |

## Overview

`AmazonS3VectorsEmbeddingRetriever` performs approximate nearest-neighbor search in an Amazon S3 vector index. Use a Document Embedder when indexing text and a matching Text Embedder for queries. Both must use the same embedding model and produce vectors matching the index dimension.

Use `top_k` to set the maximum number of results (default: 10, maximum: 10,000) and `filters` to narrow the search. Both can be set at initialization or at run time; `filter_policy` controls how runtime filters combine with initialization filters. Approximate searches can return fewer than `top_k` documents.

## Installation

```shell
pip install amazon-s3-vectors-haystack
```

## Usage

Configure AWS credentials and the region on the Document Store as described in its [Authentication](../../document-stores/amazons3vectorsdocumentstore.mdx#authentication) section; the Retriever uses that configuration.

### On its own

This example indexes two documents with illustrative vectors and retrieves the closest one:

```python
from haystack import Document
from haystack_integrations.components.retrievers.amazon_s3_vectors import (
    AmazonS3VectorsEmbeddingRetriever,
)
from haystack_integrations.document_stores.amazon_s3_vectors import (
    AmazonS3VectorsDocumentStore,
)

document_store = AmazonS3VectorsDocumentStore(
    vector_bucket_name="haystack-docs-example",
    index_name="standalone-search",
    dimension=3,
    region_name="us-east-1",
)
document_store.write_documents(
    [
        Document(id="first", content="First document", embedding=[1.0, 0.0, 0.0]),
        Document(id="second", content="Second document", embedding=[0.0, 1.0, 0.0]),
    ]
)
retriever = AmazonS3VectorsEmbeddingRetriever(document_store=document_store, top_k=1)
result = retriever.run(query_embedding=[1.0, 0.0, 0.0])
print(result["documents"][0].content)
# >> First document
retriever.close()
```

### In a Pipeline

Install Sentence Transformers for this example:

```shell
pip install sentence-transformers-haystack
```

```python
from haystack import Document, Pipeline
from haystack_integrations.components.embedders.sentence_transformers import (
    SentenceTransformersDocumentEmbedder,
    SentenceTransformersTextEmbedder,
)
from haystack_integrations.components.retrievers.amazon_s3_vectors import (
    AmazonS3VectorsEmbeddingRetriever,
)
from haystack_integrations.document_stores.amazon_s3_vectors import (
    AmazonS3VectorsDocumentStore,
)

model = "sentence-transformers/all-MiniLM-L6-v2"
document_store = AmazonS3VectorsDocumentStore(
    vector_bucket_name="haystack-docs-example",
    index_name="semantic-search",
    dimension=384,
    region_name="us-east-1",
)
documents = [
    Document(
        id="languages",
        content="There are over 7,000 languages spoken around the world today.",
    ),
    Document(id="elephants", content="Elephants can recognize themselves in mirrors."),
    Document(id="waves", content="Bioluminescent waves can be seen in the Maldives."),
]
document_embedder = SentenceTransformersDocumentEmbedder(model=model)
embedded = document_embedder.run(documents=documents)
document_store.write_documents(embedded["documents"])

query_pipeline = Pipeline()
query_pipeline.add_component(
    "text_embedder", SentenceTransformersTextEmbedder(model=model)
)
query_pipeline.add_component(
    "retriever",
    AmazonS3VectorsEmbeddingRetriever(document_store=document_store, top_k=1),
)
query_pipeline.connect("text_embedder.embedding", "retriever.query_embedding")

result = query_pipeline.run(
    {"text_embedder": {"text": "How many languages are there?"}}
)
print(result["retriever"]["documents"][0].content)
# >> There are over 7,000 languages spoken around the world today.
document_store.close()
```
