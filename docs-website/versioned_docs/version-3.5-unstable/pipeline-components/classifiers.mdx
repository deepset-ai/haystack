# Classifiers

Use Classifiers to classify your documents by specific traits and update the metadata.

| Classifier                                                                           | Description                                           |
| --- | --- |
| [DocumentLanguageClassifier](classifiers/documentlanguageclassifier.mdx)                       | Classify documents by language.                       |
| [OpenAIDecisionsDocumentClassifier](classifiers/openaidecisionsdocumentclassifier.mdx) | Answer typed questions about documents with an OpenAI Decisions model and store the answers in their metadata. |
| [TransformersZeroShotDocumentClassifier](classifiers/transformerszeroshotdocumentclassifier.mdx) | Classify the documents based on the provided labels. |
| [TypeSafeDocumentClassifier](classifiers/typesafedocumentclassifier.mdx) | Answer typed questions about documents with a TypeSafe System One model and store the answers in their metadata. |
