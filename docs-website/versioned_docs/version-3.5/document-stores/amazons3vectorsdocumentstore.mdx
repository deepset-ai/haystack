[Amazon S3 Vectors](https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-vectors.html) provides vector storage and approximate similarity search without provisioning a database server. It uses dedicated **vector buckets**, with indexes containing embeddings and metadata.

`AmazonS3VectorsDocumentStore` stores [Documents](/reference/data-classes-api#document), their dense embeddings, and supported metadata in a vector index. It does not provide keyword retrieval.

## Installation

Install the integration:

```shell
pip install amazon-s3-vectors-haystack
```

## Authentication

`AmazonS3VectorsDocumentStore` uses AWS for authentication. You can provide AWS credentials directly to the Document Store or use credentials configured through the AWS CLI.

To authenticate by providing credentials, pass `aws_access_key_id` and `aws_secret_access_key` as [Secret](../concepts/secret-management.mdx) arguments, along with `aws_session_token` for temporary credentials. Set the AWS region with `region_name`.

Make sure your AWS identity has the required [S3 Vectors permissions](https://docs.aws.amazon.com/service-authorization/latest/reference/list_s3vectors.html).

## Initialization

Provide a vector bucket name, an index name, and the embedding dimension.

```python
from haystack import Document
from haystack_integrations.document_stores.amazon_s3_vectors import (
    AmazonS3VectorsDocumentStore,
)

document_store = AmazonS3VectorsDocumentStore(
    vector_bucket_name="haystack-docs-example",
    index_name="documents",
    dimension=3,
    region_name="us-east-1",
)
document_store.write_documents(
    [
        Document(id="first", content="First document", embedding=[1.0, 0.0, 0.0]),
        Document(id="second", content="Second document", embedding=[0.0, 1.0, 0.0]),
    ]
)
print(document_store.count_documents())
# >> 2
document_store.close()
```

To learn more about the initialization parameters, see our [API docs](/reference/integrations-amazon-s3-vectors#amazons3vectorsdocumentstore).

:::info[Limitations]

- Writes overwrite documents with the same ID; `DuplicatePolicy.FAIL` and `DuplicatePolicy.SKIP` are not enforced.
- `filter_documents()` and `count_documents()` scan the index and can be slow. Prefer the retriever for similarity search.

See the [AWS limitations](https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-vectors-limitations.html) for service quotas and metadata limits.

:::
